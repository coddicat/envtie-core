# Security policy

Please report vulnerabilities privately through GitHub Security Advisories for
`coddicat/envtie-core`. Include affected versions, reproduction steps, and
impact when possible.

If private reporting is unavailable, email `coddicat@gmail.com` with the subject
“Private security report”. We aim to acknowledge reports within two business
days; this is a target, not an SLA.

Do not open a public issue for a suspected vulnerability and do not include
live credentials or customer data in a report.

Only the latest stable release and current prerelease line receive security
fixes.
