# Support

EnvTie Core is in public beta. Usage questions and hosted EnvTie.dev billing requests can be sent to
`coddicat@gmail.com`. Include the CLI version, operating system, adapter name, and safe error code. Never send provider
credentials, runner tokens, private keys, connection strings, or customer data.

Use GitHub Issues for reproducible public bugs and feature requests. Use GitHub private vulnerability reporting for
security issues. Paid hosted plans receive direct email support; response targets are described at
https://envtie.dev/support and are not an SLA.
